# 💻 Лабораторная работа №1 по предмету "Стандартизация Программного Обеспечения"
**Программа рассчёта метрики Холстеда языка "GO"**

---

## 📋 О проекте
Приложение созданное с помощью Windows forms на C# На основе анализа программа рассчитывает метрики Холстеда:
6 базовых и 3 расширенных. Результат работы программы - таблица, в которой отображаются 6 основных метрик Холстеда. Отдельно выводятся 3 расширенные метрики под основной таблицей.

---

## 🎮 Инструкция по использованию

### Шаг 1. Нажмите кнопку "Найти" и выберите файл с кодом на языке "GO"
--
### Шаг 2. Нажмите кнопку "Рассчитать" и появится таблица расчёта метрик Холстеда
